# Recorded results

`recorded_metrics.csv` transcribes selected values from the original notebooks.
`original_stdout.txt` in each analysis folder contains the saved standard-output
text, with local machine paths redacted where present. Warnings and progress-only
stderr are not included. Figures in `figures/` are copied from the original files.

No results were recomputed during the editorial pass. Some saved wording reflects
the original homework terminology; use the notebook discussion for interpretation.
`data_schema.json` records file-format and clinical-category inspection only.
